# Подключение bb.usurt.ru

MCP создаёт отдельную HTTP-сессию через HTTPcloak, не обращаясь к браузеру и не
читая его cookies. Установи npm-зависимости командой `npm ci`. Поддерживается
штатная форма входа Blackboard с `user_id` и `password`.
Если учётная запись требует дополнительный SSO шаг, MFA или CAPTCHA, автоматический
вход остановится без обхода этой проверки.

1. Установи Node.js 22 или новее.
2. Скопируй `.env.example` в `.env` и заполни `BB_USURT_USERNAME` и
   `BB_USURT_PASSWORD` локально. Не вставляй пароль в чат и не коммить `.env`.
3. Из каталога пакета запусти `npm start` для проверки MCP. При работе через MCP-хост сервер
   запускается хостом командой `node src/mcp-server.js`.

Успешная авторизация хранится только в памяти процесса. После перезапуска MCP
клиент создаст новую сессию по локальным настройкам. Cookies, nonce и тело формы
в лог не записываются.

Опционально укажи `BB_USURT_DOWNLOAD_DIR` для каталога загрузок.

Транспортные настройки задаются переменными `BB_USURT_BROWSER_PROFILE`
(по умолчанию `chrome-152-windows`) и `BB_USURT_HTTP_VERSION` (по умолчанию
`h1`). Свежая CDP-запись календаря показывает Chrome 154 на Windows и HTTP/1.1;
SDK использует тот же User-Agent и Client Hints, а HTTPcloak TLS-профиль остаётся
Chrome 152 Windows. Для календарного запроса сверены метод, путь, порядок query
параметров, доступные значения заголовков, статус, размер и структура JSON-ответа.
TLS fingerprint отличается из-за профиля Chrome 152; CDP не предоставляет
wire-порядок заголовков.
Другие маршруты имеют отдельные, более ранние browser captures.
