# Blackboard bb.usurt.ru

Используй инструменты MCP плагина bb-usurt-mcp. MCP выполняет запросы через отдельный HTTP-клиент; ему не нужны вкладка пользователя, browser cookies или запущенный браузер.

## Порядок работы

1. Проверь сессию через bb_status. Если вход не выполнен, используй bb_login. Учётные данные должны быть настроены локально в config/.env; никогда не проси отправлять пароль в чат и не выводи его.
2. Для курсов пользователя вызови bb_courses. По умолчанию рассматривай только эти курсы: не вызывай bb_search_courses для просмотра каталога и не предлагай зачисление, пока пользователь отдельно не попросит искать новые курсы или записаться. Для быстрого списка заданий с датами используй bb_list_upcoming_assignments: он получает события одним общим запросом календаря и не открывает курсы или папки. Список учитывает календари, выбранные в Blackboard. Он не сообщает статус сдачи и не показывает задания без срока. Когда нужен статус отправки или недатированные задания, используй подробный bb_list_assignments.
3. Используй только ссылки Blackboard из ответа. Для сводки отправок вызови bb_list_assignments. Открой курс через bb_open_course, затем просмотри материалы и вложенные папки через bb_list_course_items.
4. Открой страницу задания или теста через bb_open_page. Изучи текст и доступные поля. Для вложенной папки повторно вызови bb_list_course_items с её href.
5. Читай уведомления через bb_read_notifications. Для файла передай живой href в bb_download_file.
6. Ищи материалы через bb_search_course_content. Один поиск возвращает разные типы ссылок; отфильтруй file для скачивания и announcement для объявлений, не запускай три прохода подряд. Для большого числа курсов задай courseYear или courseHref. По умолчанию сканируется максимум одна папка на курс; увеличивай maxFoldersPerCourse только если результат неполон.
7. Для одного задания используй bb_assignment_details; для сводки известных статусов отправки — bb_list_my_submissions. Статус может быть unknown, если Blackboard не показывает его в HTML. Подробный список ограничен одной папкой на курс; увеличивай maxFoldersPerCourse при необходимости.
8. Для календаря используй bb_list_upcoming_assignments (сроки) или bb_list_calendar_events (все события); оба используют одну ленту, поэтому не вызывай оба без причины. Оценки читай через bb_read_grades только для конкретного courseHref; если Blackboard не показывает ссылку «Мои оценки», инструмент вернёт предупреждение.
9. bb_test_details показывает тесты со страницы курса и не запускает попытку. Запуск доступен только через bb_start_test с confirmed=true.
10. bb_list_announcements находит только объявления, на которые есть ссылки в просмотренных страницах курса; пустой результат не доказывает отсутствие отдельной ленты Blackboard.

## Действия, которые меняют данные

Зачисление, начало попытки и отправка формы могут изменить состояние учётной записи или курса. Выполняй их только по конкретному поручению пользователя.

Сначала вызови bb_enroll_course, bb_start_test или bb_submit_form без confirmed=true. Покажи план и дождись подтверждения этого действия. Затем повтори вызов с confirmed=true. Если Blackboard показывает отдельную форму подтверждения, открой её и используй актуальные pageId и formIndex.

Для задания можно вызвать bb_submit_assignment: сначала получи план без confirmed, проверь курс, задание, ответ и файл, затем отправляй только по конкретному поручению пользователя с confirmed=true. Не повторяй отправку автоматически.

Перед отправкой файла проверь, что указан нужный путь и имя. Для теста передавай в fields только ответы: скрытые nonce и значения сессии клиент получает с текущей страницы. Не угадывай значения и не подставляй поля, которых нет в форме.

## Ошибки и ограничения

Если сессия истекла, войди снова через bb_login. Если ссылка, форма или ответ отличаются от ожидаемого, открой страницу заново и используй только текущие данные Blackboard. Не заявляй об успешном зачислении, запуске теста или отправке, пока ответ Blackboard не подтверждает результат.

Перед поиском клиент проверяет живую форму каталога против браузерного эталона и прекращает отправку при расхождении. Для поиска сверяются метод, URL, content type и байты тела. Полное совпадение TLS и всех заголовков HTTPS-сессии не подтверждено. Форма загрузки файла и тестовая форма не были доступны в браузерном снимке.

Пути и ограничения запросов: [карта API](references/API_MAP.md). Локальные параметры входа и транспорта: [config/README.md](../../config/README.md).
