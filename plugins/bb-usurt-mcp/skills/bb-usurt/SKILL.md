# Blackboard bb.usurt.ru

Используй инструменты MCP плагина bb-usurt-mcp. MCP выполняет запросы через отдельный HTTP-клиент; ему не нужны вкладка пользователя, browser cookies или запущенный браузер.

## Порядок работы

1. Проверь сессию через bb_status. Если вход не выполнен, используй bb_login. Учётные данные должны быть настроены локально в config/.env; никогда не проси отправлять пароль в чат и не выводи его.
2. Для поиска в каталоге вызови bb_search_courses. Для курсов пользователя — bb_courses.
3. Используй только ссылки Blackboard из ответа. Открой курс через bb_open_course, затем просмотри материалы и вложенные папки через bb_list_course_items.
4. Открой страницу задания или теста через bb_open_page. Изучи текст и доступные поля. Для вложенной папки повторно вызови bb_list_course_items с её href.
5. Читай уведомления через bb_read_notifications. Для файла передай живой href в bb_download_file.

## Действия, которые меняют данные

Зачисление, начало попытки и отправка формы могут изменить состояние учётной записи или курса. Выполняй их только по конкретному поручению пользователя.

Сначала вызови bb_enroll_course, bb_start_test или bb_submit_form без confirmed=true. Покажи план и дождись подтверждения этого действия. Затем повтори вызов с confirmed=true. Если Blackboard показывает отдельную форму подтверждения, открой её и используй актуальные pageId и formIndex.

Перед отправкой файла проверь, что указан нужный путь и имя. Для теста передавай в fields только ответы: скрытые nonce и значения сессии клиент получает с текущей страницы. Не угадывай значения и не подставляй поля, которых нет в форме.

## Ошибки и ограничения

Если сессия истекла, войди снова через bb_login. Если ссылка, форма или ответ отличаются от ожидаемого, открой страницу заново и используй только текущие данные Blackboard. Не заявляй об успешном зачислении, запуске теста или отправке, пока ответ Blackboard не подтверждает результат.

Перед поиском клиент проверяет живую форму каталога против браузерного эталона и прекращает отправку при расхождении. Для поиска сверяются метод, URL, content type и байты тела. Полное совпадение TLS и всех заголовков HTTPS-сессии не подтверждено. Форма загрузки файла и тестовая форма не были доступны в браузерном снимке.

Пути и ограничения запросов: [карта API](references/API_MAP.md). Локальные параметры входа и транспорта: [config/README.md](../../config/README.md).
