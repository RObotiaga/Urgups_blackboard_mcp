# Карта Blackboard API

Это карта наблюдавшихся запросов `https://bb.usurt.ru`. Значения пользовательских
идентификаторов, cookies, nonce, тело DWR-вызовов и данные учётной записи в
снимок не включены.

## Динамический модуль списка курсов

В HTML вкладки Blackboard «Курсы» курсы не присутствуют сразу: страница показывает
заглушку и запускает `Ajax.Request` при загрузке. SDK теперь находит модуль по
marker `learning/coursetab-courses`, извлекает endpoint, метод и строку
`parameters` из текущей страницы и отправляет её в исходном порядке. Ответ XML
разбирается как `<contents>`/CDATA; скрипты из содержимого не исполняются.

Запрос динамического модуля также записан в CDP на вкладке «Курсы»: метод, путь,
порядок имён полей, статическое `action`, длина тела (69 байт), `Content-type`,
`Origin`, `X-Prototype-Version`, `X-Requested-With`, `Accept` и `Sec-Fetch-*`.
Сессионные значения `modId`/`tabId` не сохранены. Живой SDK получил успешный ответ
и ссылки курсов; его тело совпадает по форме и длине, а заголовки `Origin` и
`X-Prototype-Version`, которых не хватало, добавлены. Точные динамические значения,
порядок wire-заголовков и TLS fingerprint не сравнивались.

`bb_list_assignments` обходит текущие ссылки `listContent.jsp`, затем читает
страницы `uploadAssignment` и возвращает дату выполнения, если она указана,
и признак доступной формы отправки. По умолчанию проверяется не более одной
папки каждого курса; `complete=false` и `warnings` сообщают о неполном обходе.
Увеличь `maxFoldersPerCourse` или сузь выбор по `courseYear`/`courseHref`, если
нужна полнота. По умолчанию уже отправленные и недоступные задания исключаются.
Страницы тестов не открываются и попытки не запускаются.

`bb_list_upcoming_assignments` следует глобальному календарю Blackboard, а не
содержимому курсов:

| Шаг | Метод | Путь | Назначение |
|---|---|---|---|
| Открыть календарь | `GET` | `/webapps/blackboard/execute/viewCalendar` → `/webapps/calendar/viewPersonal` | Живая ссылка берётся из вкладки портала; первый путь перенаправляет на календарь пользователя |
| События выбранных календарей | `GET` | `/webapps/calendar/calendarData/selectedCalendarEvents` | Один запрос для диапазона дат; Blackboard сам применяет выбранные пользователем календари |

Параметры и порядок `start`, `end`, `course_id`, `mode` соответствуют запросу,
который браузер отправил при открытии календаря. `course_id` пустой, `mode`
равен `personal`. Браузерная запись и SDK используют один маршрут и заголовки
`Accept: */*`, `X-Requested-With: XMLHttpRequest`; диапазон дат различается,
поскольку SDK позволяет запросить произвольное число дней.
Поток содержит только события календаря с датой. Инструмент отбирает события,
которые Blackboard помечает как «Задание», и возвращает поле `attemptable`, но
не определяет факт отправки и не обнаруживает задания без срока. Для этих задач
используй подробный `bb_list_assignments`, который открывает страницы курсов.
## Проверенный запрос поиска

| Действие | Метод | Путь | Тело |
|---|---|---|---|
| Источник живой формы на вкладке «Курсы» | `GET` | `/webapps/portal/execute/tabs/tabAction` | Параметр вкладки динамический |
| Поиск курсов | `POST` | `/webapps/blackboard/execute/viewCatalog` | `type=Course&command=NewSearch&searchText=...` |

В `captures/browser-observed.json` сохранена только безопасная форма запроса
`searchText=2026`. Поля были прочитаны из `FormData` живой формы при клике по
штатной кнопке вкладки «Курсы». SDK загружает эту форму, сохраняет порядок
полей и побайтно сверяет тело, URL, метод и `content type` перед отправкой.
Значения динамической вкладки и поля поиска в снимок не заносятся.

## Наблюдавшиеся маршруты

| Действие | Метод | Путь | Примечание |
|---|---|---|---|
| Список курсов: вкладка | `GET` | `/webapps/portal/execute/tabs/tabAction` | Живой href вкладки «Курсы» из портала |
| Загрузка модуля списка курсов | `POST` | `/webapps/portal/execute/tabs/tabAction` | Захвачены `action=refreshAjaxModule`, порядок полей и заголовки; динамические ID извлекаются из inline `Ajax.Request` текущей страницы |
| Открытие курса | `GET` | `/webapps/blackboard/execute/launcher` | Используй живой href курса |
| Главная курса | `GET` | `/webapps/blackboard/execute/courseMain` | Blackboard перенаправляет по ссылке курса |
| Содержимое курса | `GET` | `/webapps/blackboard/content/listContent.jsp` | Используй href папки/раздела |
| Инструмент курса | `GET` | `/webapps/blackboard/content/launchLink.jsp` | Используй href из курса |
| Страница задания | `GET` | `/webapps/assignment/uploadAssignment` | Требуются текущие `content_id`, `course_id`, `group_id`, `mode` |
| Файл курса | `GET` | `/bbcswebdav/pid-<content-id>-dt-content-rid-<file-id>_1/xid-<file-id>_1` | Используй живой href из материала |
| Файл попытки задания | `GET` | `/webapps/assignment/download` | Параметры берутся из живой ссылки |
| Мои оценки | `GET` | `/webapps/bb-mygrades-BBLEARN/myGrades` | Требуются актуальные параметры курса |
| Activity Stream | `GET` | `/webapps/streamViewer/streamViewer` | Динамические параметры берутся из живой ссылки |
| Панель уведомлений | `GET` | `/webapps/portal/execute/tabs/tabAction` | Href с `tabId` и `tab_tab_group_id` берётся из живой ссылки |
| Уведомления DWR | `POST` | `/webapps/portal/dwr_open/call/plaincall/NautilusViewService.getEwsViewInfo.dwr` | `text/plain`; live request совпал с SDK по 289 байтам, полям и безопасным заголовкам |
| Зачисление | `GET` | `/webapps/blackboard/execute/enrollCourse` | Выполняй только после подтверждения |

Список заданий, тестов, файлов и форм строится по актуальным ссылкам и HTML.
Формы отправляются с их текущим action, method, enctype, порядком controls и
скрытыми значениями. Multipart сериализуется в порядке полей HTML; граница
генерируется заново с префиксом WebKit, поэтому полное тело загрузки зависит от
имени файла, содержимого и случайной границы.

## Границы проверки

Для поиска побайтно сопоставлены тело живой формы и SDK, а CDP сохранил значения
безопасных заголовков и успешный ответ. CDP не предоставил сырой wire-порядок
заголовков. Для запроса модуля курсов сопоставлены маршрут, порядок и длина тела,
статические поля и значения доступных заголовков. Для панели уведомлений live
SDK и браузер совпали по маршруту, методу, content type, порядку полей,
статическим значениям, размерам динамических значений, длине тела и безопасным
заголовкам. Cookie, session ID и параметры вкладки не сохраняются. Открытие
глобального меню отправляет отдельный `ToolActivityService` DWR-вызов с
`boolean:true` и текущим batch ID; `bb_read_notifications` его не вызывает.
Начальная страница входа сверена по значениям заголовков; CDP sample не
сохраняет wire-порядок.

## Добавленные инструменты SDK

`bb_list_calendar_events` использует тот же наблюдавшийся календарный маршрут,
что `bb_list_upcoming_assignments`, но возвращает все типы событий в диапазоне.
`bb_assignment_details` читает одну страницу
`/webapps/assignment/uploadAssignment`; `bb_list_my_submissions` повторно
использует видимый статус с этих страниц. Это эвристика по серверному HTML, а не
отдельный API отправок. `bb_submit_assignment` строит запрос из актуальной
HTML-формы, требует сначала план без отправки и затем явный `confirmed=true`;
точная форма отправки файла или ответа браузерным захватом не сверялась.

`bb_search_course_content`, `bb_search_course_files` и
`bb_list_announcements` обходят ссылки и папки, обнаруженные на курсах текущей
вкладки «Курсы». Они не читают каталог и не зачисляют пользователя. Поиск идёт
по названию ссылки. Обход переходит только в `listContent.jsp`, не в инструменты
курса; по умолчанию читается не более одной папки каждого курса. Индекс ссылок
хранится в памяти 5 минут и повторно используется между тремя поисками. В живой
проверке обход всех курсов потребовал много запросов; `requestCount` возвращает
точную стоимость прохода. Укажи `courseYear`/`courseHref`, чтобы уменьшить область,
или увеличь предел ради полноты. Объявления обнаруживаются только если курс
показывает на них ссылки. `bb_test_details` читает список тестовых ссылок на странице курса и
намеренно не открывает ссылку запуска, чтобы не создать попытку.

`bb_read_grades` требует `courseHref`, использует ссылку «Мои оценки», если она
присутствует на странице этого курса, затем извлекает строки HTML-таблиц. Ссылка
может отсутствовать на отдельных курсах. Разметка Blackboard может отличаться;
таблица оценок не была захвачена в текущем браузерном снимке, поэтому её
структура требует проверки на актуальном курсе.

Маршрут чтения и скачивания файлов наблюдался в браузере. Тестовая форма и
форма загрузки файла не были доступны в проверенной странице задания; тест не
запускался, файл не отправлялся. Для этих операций MCP поддерживает только
актуальные same-origin HTML-формы, а точное соответствие конкретным Blackboard
маршрутам пока не подтверждено браузерным снимком.
